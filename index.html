ACCESORIOS VEHICULARES

Accesorios para sistemas MDVR y videotelemática

Complementos para ampliar las aplicaciones de monitoreo, seguridad y gestión vehicular. Consulte compatibilidad y configuración para cada instalación.

Adaptador OBD para iVMS

Integración con el bus CAN para consultar datos del vehículo, comportamiento de conducción y diagnóstico, según compatibilidad.

Características técnicas

Análisis de aceleraciones, frenadas y giros; datos de kilometraje y consumo; lectura de estados y funciones de control compatibles.

Botón de pánico

Alarma manual de emergencia conectada al MDVR para generar eventos y avisos al centro de monitoreo.

Características técnicas

Botón metálico; vinculación con video en vivo; capturas de alarma e informes en iVMS, con configuración del MDVR.

UPS de respaldo para MDVR

Fuente de alimentación de respaldo que permite mantener temporalmente operativo el MDVR ante interrupciones de energía.

Características técnicas
